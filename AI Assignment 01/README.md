## Project Overview

This project implements an **A* search algorithm** for solving dynamic maze pathfinding problems. The algorithm finds the optimal path from a start position to a goal position in a grid-based environment with obstacles. The implementation features object-oriented design, real-time visualization, and comprehensive statistics tracking.

---

## Features

### Core Features
A* search algorithm implementation
Manhattan and Euclidean distance heuristics
Grid-based maze generation with random obstacles
Path visualization with color-coded cells
Step-by-step search visualization
Comprehensive search statistics

### Technical Features
Object-oriented design with encapsulation
Type hints for better code readability
Exception handling and input validation
Modular architecture
Efficient priority queue using heapq
